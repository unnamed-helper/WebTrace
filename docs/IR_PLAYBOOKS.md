# IR Playbook Guide

The application includes investigation and remediation guidance for detected categories.

## Playbook structure

Each playbook has two parts:

### How to Investigate

Focused checks for validating the alert and building context.

### Remediation Steps

Actions to consider after validation and evidence preservation.

## Current playbook categories

- Cross-Site Scripting (XSS)
- RCE / Command Injection
- Web Shell Activity
- SQL Injection (SQLi)
- Path Traversal / LFI
- File Inclusion Wrapper
- Server-Side Request Forgery (SSRF)
- Log4Shell / JNDI Injection
- Sensitive File / Config Exposure Probe
- XXE / XML Entity Injection
- Server-Side Template Injection (SSTI)
- HTTP Request Smuggling / CRLF Probe
- Automated Recon Scanner
- Custom Web Shell / Backdoor
- Custom Internal Policy Violation
- Behavioral brute-force / 401 detection
- Repeated 403 probing
- 404 reconnaissance storm

## Add or update a playbook

Edit `IR_PLAYBOOKS` in the HTML.

The playbook key must exactly match the detection category.

Example:

```javascript
'Custom Example': {
  investigate: [
    'Review the source IP and request context.',
    'Correlate with authentication and endpoint telemetry.'
  ],
  remediate: [
    'Validate the activity before containment.',
    'Apply the appropriate access-control or application fix.'
  ]
}
```

## Remove a playbook

Delete its object from `IR_PLAYBOOKS`. The engine will fall back to the generic investigation/remediation guidance if the category is still generated by a detection rule.
