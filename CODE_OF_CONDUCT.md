# Code of Conduct

Contributors are expected to communicate professionally and respectfully.

Please:

- Be constructive when reviewing code or documentation.
- Focus criticism on the work, not the person.
- Respect different levels of technical experience.
- Do not publish private, confidential, or real investigation evidence.
- Do not submit credentials, secrets, customer data, or personal information in issues or pull requests.

Project maintainers may remove content that creates a security, privacy, or harassment risk.
